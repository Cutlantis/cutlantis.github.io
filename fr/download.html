Cinq minutes, une seule fois

Sur Mac

  1. Ouvrez le fichier téléchargéCutlantis-1.4.0.dmg, dans votre dossier Téléchargements.
  2. Glissez Cutlantis dans ApplicationsPuis éjectez l'image disque (flèche à côté de son nom dans le Finder).
  3. Ouvrez CutlantisLa première fois, macOS affiche « Élément « Cutlantis » non ouvert ». Cliquez sur Terminé (surtout pas « Placer dans la corbeille »), ouvrez Réglages Système → Confidentialité et sécurité, puis « Ouvrir quand même » en bas de la page. On ne vous le redemandera plus.
  4. Collez un lien YouTubeEn mode automatique, Cutlantis propose les clips ; en mode manuel, vous choisissez les passages.
  5. Activez votre licenceCollez la clé reçue par e-mail dans le champ « Votre clé de licence », puis cliquez sur Activer. Internet est nécessaire une seule fois.

En cas de souci

« Cette clé est déjà activée sur le nombre maximum d'ordinateurs »

Ouvrez Cutlantis sur l'ancien ordinateur et cliquez « Désactiver sur cet ordinateur » sous votre licence. Plus accès à l'ancien ordinateur ? Écrivez-nous.

Un téléchargement YouTube échoue

YouTube change régulièrement ; Cutlantis met à jour son module YouTube tout seul, une fois par jour. Quittez et relancez l'app ; si le problème dure, écrivez-nous.

Nous envoyer le journal

Mac : menu Aide → Afficher le journal. Windows : le fichier %LOCALAPPDATA%\Cutlantis\logs\cutlantis.log. Joignez-le à votre message : il nous montre ce qui s'est passé.

Désinstaller

Mac : glissez Cutlantis dans la corbeille ; vos projets restent dans Bibliothèque › Application Support › Cutlantis. Windows : Paramètres → Applications → Cutlantis → Désinstaller ; vos projets restent dans %LOCALAPPDATA%\Cutlantis. Supprimez ce dossier pour tout effacer.
