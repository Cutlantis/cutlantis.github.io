在 Mac 上

  1. 打开下载的文件「下载」文件夹中的 Cutlantis-1.4.0.dmg。
  2. 把 Cutlantis 拖到「应用程序」然后推出磁盘映像（在访达中点击名称旁的箭头）。
  3. 打开 Cutlantis第一次打开时，macOS 可能提示「Apple 无法验证……」。点击「完成」，打开「系统设置」→「隐私与安全性」，然后点击页面底部的「仍要打开」。之后不会再提示。
  4. 粘贴一个 YouTube 链接自动模式下由 Cutlantis 推荐切片；手动模式下由你来选片段。
  5. 激活授权把邮件中的密钥粘贴到「Your licence key」栏（应用界面为英文），然后点击「Activate」。只需联网一次。

在 Windows 上

  1. 打开下载的文件「下载」文件夹中的 Cutlantis-Setup-1.4.0.exe。
  2. 如果 Windows 提示「Windows 已保护你的电脑」点击「更多信息」，然后点击「仍要运行」。
  3. 按提示完成安装无需管理员权限：Cutlantis 会安装到你的账户下，并在「开始」菜单中创建快捷方式。无需安装其他任何东西。
  4. 粘贴一个 YouTube 链接自动模式下由 Cutlantis 推荐切片；手动模式下由你来选片段。

遇到问题时

「此密钥已在最多数量的电脑上激活」

在旧电脑上打开 Cutlantis，点击授权下方的「Deactivate on this computer」（应用界面为英文）。旧电脑已不在手边？请联系我们。

YouTube 下载失败

YouTube 经常变化；Cutlantis 每天会自动更新一次 YouTube 模块。退出并重新打开应用；如果问题仍然存在，请联系我们。

把日志发给我们

Mac：「帮助」菜单 →「显示日志」。Windows：文件 %LOCALAPPDATA%\Cutlantis\logs\cutlantis.log。请把它附在邮件里，我们就能看到发生了什么。

卸载

Mac：把 Cutlantis 拖到废纸篓，项目保存在 资源库 › Application Support › Cutlantis。Windows：设置 → 应用 → Cutlantis → 卸载，项目保存在 %LOCALAPPDATA%\Cutlantis。删除该文件夹即可清除全部内容。
