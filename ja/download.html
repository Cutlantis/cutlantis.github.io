Macの場合

  1. ダウンロードしたファイルを開く「ダウンロード」フォルダにある Cutlantis-1.4.0.dmg です。
  2. Cutlantisを「アプリケーション」へドラッグその後ディスクイメージを取り出します（Finderで名前の横の矢印）。
  3. Cutlantisを開く初回、macOSに「Appleは…を検証できませんでした」と表示されることがあります。「完了」をクリックし、システム設定 → プライバシーとセキュリティを開いて、ページ下部の「このまま開く」を選んでください。次回からは表示されません。
  4. YouTubeのリンクを貼る自動モードではCutlantisがクリップを提案し、手動モードでは場面をあなたが選びます。
  5. ライセンスを有効にするメールで届いたキーを「Your licence key」欄（アプリは英語表示です）に貼り付け、「Activate」をクリック。インターネット接続は一度だけ必要です。

Windowsの場合

  1. ダウンロードしたファイルを開く「ダウンロード」フォルダにある Cutlantis-Setup-1.4.0.exe です。
  2. 「WindowsによってPCが保護されました」と表示された場合「詳細情報」をクリックし、「実行」を選んでください。
  3. インストールを進める管理者権限は不要です。Cutlantisはお使いのアカウントにインストールされ、スタートメニューにショートカットが作られます。ほかに必要なものはありません。
  4. YouTubeのリンクを貼る自動モードではCutlantisがクリップを提案し、手動モードでは場面をあなたが選びます。
  5. ライセンスを有効にするメールで届いたキーを「Your licence key」欄（アプリは英語表示です）に貼り付け、「Activate」をクリック。インターネット接続は一度だけ必要です。

困ったときは

「このキーは最大台数のパソコンで有効化済みです」

以前のパソコンでCutlantisを開き、ライセンスの下の「Deactivate on this computer」（アプリは英語表示です）をクリックしてください。以前のパソコンが手元にない場合はご連絡ください。

YouTubeのダウンロードに失敗する

YouTubeは頻繁に変わりますが、CutlantisはYouTubeモジュールを1日1回自動で更新します。アプリを終了して開き直してください。解決しない場合はご連絡ください。

ログを送る

Mac：ヘルプメニュー → ログを表示。Windows：%LOCALAPPDATA%\Cutlantis\logs\cutlantis.log。メッセージに添付していただくと、何が起きたかがわかります。

アンインストール

Mac：Cutlantisをゴミ箱へドラッグ。プロジェクトはライブラリ › Application Support › Cutlantis に残ります。Windows：設定 → アプリ → Cutlantis → アンインストール。プロジェクトは %LOCALAPPDATA%\Cutlantis に残ります。すべて消すにはこのフォルダを削除してください。
